# Pop Roll Mini App

Первый тестовый интерфейс Telegram Mini App для Pop Roll.

## Файлы
- `index.html` — страница приложения
- `style.css` — дизайн
- `app.js` — меню, корзина и оформление заказа
- `logo.jpeg` — логотип

## Важно
Не добавляйте токен Telegram-бота в эти файлы и не публикуйте его на GitHub.

## Публикация через GitHub Pages
После загрузки файлов откройте:
Settings → Pages → Deploy from a branch → main / root → Save.
